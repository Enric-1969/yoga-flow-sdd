# Contexto del Proyecto: Yoga Flow

## Descripción General
Aplicación web de gestión operativa para el estudio de yoga "Yoga Flow", dirigida por la instructora Andrea. Su objetivo es digitalizar el control de paquetes de clases, cupos vespertinos y avisos urgentes, eliminando el uso de tarjetas de papel y llamadas caóticas.

## Stack Tecnológico y Reglas de Arquitectura
- **Frontend:** React con Tailwind CSS y componentes modulares de shadcn/ui.
- **Diseño Responsive:** Enfoque Mobile-First. Totalmente adaptable a dispositivos móviles (uso táctil sencillo para alumnas) y ordenadores/tablets (paneles de control amplios para la instructora).
- **Arquitectura:** Código limpio, desacoplado y modular, preparado para su posterior integración con un backend (patrón MVC o API REST).
- **Estética Visual:** Minimalista, limpia, tonos relajantes (blancos, grises suaves, acentos en verde salvia), con soporte para modo claro y oscuro.
