# ICP y User Persona — Yoga Flow

## 1. Ideal Customer Profile (ICP)
- **Segmento:** Estudios de yoga boutique y centros de bienestar holístico urbanos.
- **Modelo de Negocio:** Membresías recurrentes mensuales (Socio Premium / Estándar) con clases de cupo limitado.
- **Problema Principal:** Gestión manual e ineficiente de listas de espera y baja velocidad de comunicación de avisos o cambios de última hora (ej. cambio de sala o profesor).
- **Propuesta de Valor:** Automatización transparente de reservas, gestión dinámica de cupos sin sobreventas y panel de avisos urgentes en tiempo real.
